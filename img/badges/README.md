# Certification badge artwork

The certifications section shows a badge image per credential. Files here are
matched by name; any that are missing fall back to an initials tile, so the
section never breaks.

| File | Credential | Status |
| --- | --- | --- |
| `gen_ai_leader.png` | Generative AI Leader, Google | present |
| `cloud_architect.png` | Professional Cloud Architect, Google | present |
| `ai_expert.png` | AI Expert, UPS University / Percipio | present |
| `safe_architect.png` | SAFe for Architects, Scaled Agile | missing, shows the initials tile |

Square PNGs work best. They render at 92px, so anything from 200px up is
plenty. Transparent corners are ideal; artwork with an opaque light background
is rounded slightly so it reads as a tile. The Toptal card draws the seal
component and needs no file.
