# Certification badge artwork

The certifications section shows a badge image per credential. Drop the files
here with these exact names and they appear automatically; any that are missing
fall back to an initials tile, so the section never breaks.

| File | Credential | Where to get it |
| --- | --- | --- |
| `google-generative-ai-leader.png` | Generative AI Leader, Google | Credly badge page, Share, Download badge |
| `google-cloud-architect.png` | Professional Cloud Architect, Google | Credly badge page, Share, Download badge |
| `ai-expert.png` | AI Expert, UPS University / Percipio | Skillsoft digital badge page, Download |
| `safe-architect.png` | SAFe for Architects, Scaled Agile | Scaled Agile community profile, Download certificate badge |

Square PNGs with a transparent background work best. They render at 96px, so
anything from 200px up is plenty. The Toptal card draws the seal component and
needs no file.
